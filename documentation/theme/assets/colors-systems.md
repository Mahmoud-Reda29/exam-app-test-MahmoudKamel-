This document defines the **core colors** used across the project.  
These colors are the foundation of the design system and should be used consistently to ensure brand recognition and visual harmony.

## Primary Colors
- **Primary** – The main brand color used for key actions and highlights.  
  Example: `#1E88E5`

- **Secondary** – A complementary color used to support the primary palette.  
  Example: `#F9FAFB`

## Neutral Colors
- **Background** – Default background color for pages and containers.  
  Example: `#FFFFFF`

- **Text** – Default color for body text and headings.  
  Example: `#000000`

## Accent Colors
- **Accent** – Used sparingly to draw attention to specific UI elements.  
  Example: `#dc2626`
