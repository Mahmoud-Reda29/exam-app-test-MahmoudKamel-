# Core Typography

This document outlines the **primary font styles** used in the project.  
Typography plays a critical role in maintaining brand identity, readability, and accessibility.

## Primary Typeface
- **Font Family**: `Geist_Mono`
- **Usage**: Default body text and UI elements  
- **Weights**: `400 (Regular)`, `500 (Medium)`, `600 (Semi-Bold)`

## Secondary Typeface
- **Font Family**: `Inter`
- **Usage**: Headings, titles, and emphasis elements  
- **Weights**: `600 (Semi-Bold)`, `700 (Bold)`

---

## Font Sizes (Baseline)
- **Heading 1 (H1)**: `32px / 2rem`
- **Heading 2 (H2)**: `20px / 1.25rem`
- **Body**: `16px / 1rem`
- **Caption / Small Text**: `14px / 0.875rem`
