# Image Assets

This project enforces the use of **WebP format** for all images to ensure better performance and optimization across the application.  

---

## Location
All image files must be stored inside the following directory: `/public/images/` This provides a centralized and predictable structure for handling image assets.

---

## Why WebP?
WebP is chosen as the standard image format because it provides significant advantages over traditional formats (JPEG, PNG):

1. **Smaller File Size** – WebP images are typically 25–35% smaller than JPEG/PNG with the same quality, reducing load times.  
2. **Better Quality** – Supports both lossy and lossless compression, maintaining crisp image quality at lower file sizes.  
3. **Modern Features** – Supports transparency (like PNG) and animation (like GIF), making it versatile for modern web applications.  

---

> Note: Always optimize images before uploading to `/public/images/` to avoid unnecessary bandwidth usage and to keep performance at the highest level.
